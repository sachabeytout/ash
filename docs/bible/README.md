# Bible narrative d'ASH

Créée le 02/11/2026. **On repart de zéro** : l'ancien lore (`docs/LORE.md`, v0.4) est archivé, il n'est plus la
référence. Rien de cette bible n'est encore dans le jeu.

## Légende

| Marque | Sens                                                                        |
| ------ | --------------------------------------------------------------------------- |
| ✅     | Validé par l'utilisateur (ses idées, ou une proposition qu'il a acceptée).  |
| 🟡     | Proposition de Claude, **pas validée**. Ne jamais la traiter comme acquise. |
| ❓     | Question ouverte (détail dans `07-questions-ouvertes.md`).                  |
| ❌     | Abandonné ou rejeté (raison dans `08-idees-abandonnees.md`).                |

## Méthode de travail

- Une étape à la fois ; questions par petits groupes ; au moins 3 propositions argumentées quand plusieurs pistes sont
  possibles ; **rien n'est validé sans l'accord de l'utilisateur**.
- Toute nouvelle idée doit respecter `02-regles-du-monde.md`. Si elle les contredit, on le dit et on tranche.
- Les mythologies réelles servent de matière ; l'histoire et les personnages sont originaux. Aucun élément de Hadès /
  Supergiant.
